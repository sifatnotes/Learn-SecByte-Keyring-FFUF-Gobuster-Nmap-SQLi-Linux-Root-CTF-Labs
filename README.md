## Learning Path

A practical progression through this collection is:

1. Start with **Keyring Lab Kickoff** to establish familiarity with the Keyring environment.
2. Practice **Keyring Web Trail** and **Keyring Service Hunt** for web and service reconnaissance.
3. Continue with **Port Shadow Nmap Recon** to strengthen network enumeration skills.
4. Study **FFUF Parameter Forge** and **Gobuster Hidden Paths and Files** for web discovery.
5. Explore **Session Cookie Shadows** for session-related web-security concepts.
6. Move to **Keyring SQLi to SUID** to connect web vulnerability discovery with Linux privilege concepts.
7. Practice **DNS Drift to Root** for DNS-focused discovery and root-access concepts.
8. Finish with **Ptrace to Root**, **CapTrail Linux Capability Hunt**, and **Root Shell Rendezvous** for Linux privilege-escalation practice.

## How to Use the Labs

- Read each lab's instructions before beginning.
- Use the techniques only within the authorized CTF or training environment.
- Record discovered services, endpoints, parameters, and security observations.
- For FFUF and Gobuster labs, understand what is being enumerated and why.
- For Nmap exercises, document discovered ports and services.
- For SQL injection challenges, understand the vulnerability rather than relying solely on automated tools.
- For SUID, ptrace, and Linux capability labs, study the underlying security configuration.
- Treat all credentials, cookies, keys, and flags as lab-only information.
- Never test these techniques against systems without explicit authorization.
